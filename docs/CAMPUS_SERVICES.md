# Campus Services, Marketplace & Profile Module
**Module Contributor**: Member 3

### Implemented Components:
- **Marketplace**: Buy & sell campus items, filter categories, create listings with photos.
- **Lost & Found**: Item loss and recovery reporting with photo uploads.
- **Student Profile**: Editable bio, department, skills, and NMIMS campus resources integration.
- **Cloud Sync**: Firebase Firestore real-time data persistence.
